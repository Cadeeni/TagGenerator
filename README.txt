Work Marker Tag Generator (standalone)

Open index.html in a browser (Chrome, Edge, Firefox or Safari). It needs an internet
connection the first time to load Anton from Google Fonts and three small libraries
(opentype.js, earcut, JSZip) from cdnjs/jsDelivr.

Type the box text and side letter, check the preview, then click "Download 3MF".
Open the .3mf in Bambu Studio or OrcaSlicer. White areas are filament 1, black are filament 2.

To host it free on GitHub Pages: put index.html in a repo, then Settings > Pages.
Nothing is saved or sent anywhere; all of it runs in your browser.
